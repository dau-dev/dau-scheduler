## Pre-requisites

You need Python >=3.10 on your machine to install `dau-scheduler`.

## Install with `pip`

```bash
pip install dau-scheduler
```

## Install with `conda`

```bash
conda install dau-scheduler --channel conda-forge
```

## Source installation

For other platforms and for development installations, [build `dau-scheduler` from source](Build-from-Source).
