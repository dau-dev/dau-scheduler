## Pre-requisites

You need Python 3.12 or newer. The only runtime dependency is pydantic.

## Install from the repository

```bash
pip install git+https://github.com/dau-dev/dau-scheduler
```

The `dau-scheduler` name on PyPI is a placeholder until the first release.

## Source installation

For development installations, [build `dau-scheduler` from source](Build-from-Source).
