test_profile.test_fixed_cost_is_not_scaled_by_the_row_count() → None¶

Plan-time work does not grow with data, and folding it into a per-row rate over-estimates a large query by orders of magnitude.

test_profile.test_a_profile_refuses_numbers_it_cannot_price_with() → None¶
test_profile.test_a_node_cost_refuses_a_nan() → None¶

NaN fails every comparison, so a bare < 0 check admits it and it then propagates through every estimate built on it.

test_profile.test_a_profile_goes_stale_when_the_row_count_moves_too_far() → None¶

Extrapolating one measurement across orders of magnitude is where a profile-guided split goes confidently wrong.

test_profile.test_a_profile_goes_stale_under_a_different_engine() → None¶

A measurement taken under one build says nothing about another, and this module exists BECAUSE an analytic model of that engine would be guesswork.

test_profile.test_an_unrecorded_engine_version_is_unknown_and_therefore_stale() → None¶

It may have been measured under anything – defaulting to the installed build would let a hand-written profile claim a measurement it never made.

test_profile.test_the_profile_prices_a_split() → None¶

What the measurement is for: the closed form takes the host figure from it instead of the caller inventing one.

test_profile.test_overlapping_nodes_are_not_summed_into_elapsed_time() → None¶

Summing end - start double-counts the overlap and drops the gaps: with these spans the true elapsed cost is 15 ms and the sum reports 21.

test_profile.test_gaps_between_nodes_are_real_elapsed_cost() → None¶

Anything not attributed to a plan-time node scales, including the time the engine spent between the nodes it reported.

test_profile.test_fixed_nodes_count_their_overlap_once() → None¶
test_profile.test_every_node_is_kept_with_its_own_cost() → None¶

The per-node breakdown is what a boundary-choosing planner needs; the whole-query figure is what the closed form needs. One measurement serves both.

test_profile.test_a_profile_needs_timings_and_a_row_count() → None¶
test_profile.test_the_host_is_part_of_the_identity() → None¶

Two machines running the same query differed ~1.6x in one measurement, so a profile keyed by plan alone steers a split on the wrong one.

test_profile.test_the_cache_round_trips_by_plan_and_host(tmp_path) → None¶
test_profile.test_an_empty_cache_directory_lists_nothing(tmp_path) → None¶
test_profile.test_the_engine_version_is_not_part_of_the_key(tmp_path) → None¶

A host is a key because you cannot re-measure on a machine you are not on; an engine version is not, because you can always re-measure under the one you have. So it is staleness, not a second slot on disk.

test_profile.test_a_link_rate_is_keyed_by_host_device_and_transfer_size_and_round_trips(tmp_path) → None¶

The rate the cut model prices every byte crossing with is a measured fact about one host’s link to one device at one transfer size, kept beside the host profiles and deletable by hand like them.

test_profile.test_a_copied_profile_is_checked_where_it_is_used(tmp_path) → None¶

model_copy(update=...) skips validation, so an invalid copy must be caught at the use site rather than priced: estimating with it, asking whether it is stale, and caching it all refuse.

test_profile.test_a_copied_link_rate_is_checked_where_it_is_used(tmp_path) → None¶
test_profile.test_models_refuse_fields_they_do_not_declare() → None¶
test_profile.test_a_reversed_or_negative_span_is_a_reporting_fault_not_a_cheap_node(spans) → None¶
test_profile.test_cache_entries_stay_directly_under_the_root(tmp_path) → None¶

A plan key or host is caller text. One containing a slash or .. must not name a file outside the cache, and two keys that differ only in such characters must not collide.
